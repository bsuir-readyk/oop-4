# Лабораторная работа: Основы ООП на C++

## Иерархия классов

В проекте реализована трёхуровневая иерархия из 7 классов на тему транспортных средств:

```
Vehicle (абстрактный базовый класс)
├── LandVehicle (наземный транспорт, абстрактный)
│   ├── Car (легковой автомобиль)
│   └── Truck (грузовик)
└── WaterVehicle (водный транспорт, абстрактный)
    ├── Boat (катер)
    └── Submarine (подводная лодка)
```

Дополнительные классы: `Engine` (двигатель), `Driver` (водитель), `Fleet` (коллекция транспорта).

## Принципы ООП

**Инкапсуляция.** Все данные классов объявлены как `private` (например, `max_speed_`, `name_`, `engine_`). Доступ осуществляется через публичные геттеры и сеттеры (`GetMaxSpeed()`, `SetCurrentSpeed()`). Это защищает внутреннее состояние объекта от некорректного использования. Например, `SetCurrentSpeed()` проверяет допустимый диапазон и бросает исключение при превышении лимита.

**Наследование.** Три уровня: `Vehicle` -> `LandVehicle` -> `Car`. Каждый уровень добавляет свои поля и методы. `LandVehicle` добавляет количество колёс, `Car` — количество мест. Конструкторы вызываются по цепочке от базового к производному, деструкторы — в обратном порядке.

**Полиморфизм.** Методы `Move()` и `GetInfo()` объявлены как `virtual` в базовом классе. При вызове через указатель `Vehicle*` выполняется версия конкретного класса. Например, `Car::Move()` возвращает "едет по дороге", а `Submarine::Move()` — "погружается под воду". Это позволяет обрабатывать разнородную коллекцию единообразно.

**Абстракция.** `Vehicle` содержит чисто виртуальные методы (`= 0`): `GetType()` и `Move()`. Это делает класс абстрактным — нельзя создать его экземпляр напрямую, но можно использовать указатель на него для полиморфной работы.

## Что содержит класс

- **Поля (fields)** — данные объекта: `max_speed_`, `name_`, `engine_`. Хранят состояние.
- **Методы (methods)** — поведение: `Move()`, `GetInfo()`, `Start()`. Определяют, что объект умеет делать.
- **Свойства (properties)** — в C++ реализуются через пары геттер/сеттер: `GetName()`, `SetCurrentSpeed()`. Обеспечивают контролируемый доступ к полям.
- **Конструктор** — `Vehicle(name, max_speed, engine_hp, fuel_type)` — инициализирует объект при создании. Вызывается автоматически при `new` или создании на стеке.
- **Деструктор** — `~Vehicle()` — вызывается при уничтожении объекта. Освобождает ресурсы. Объявлен `virtual` для корректного удаления через базовый указатель.
- **Индексатор** — `operator[]` в классе `Fleet` — доступ к элементам коллекции по индексу с проверкой границ.
- **Атрибуты** — модификаторы: `virtual`, `override`, `const`, `explicit`, `= 0`. Управляют поведением компилятора: `const` запрещает изменение, `override` проверяет наличие виртуального метода в базовом классе.

## Агрегация и композиция

**Композиция** (Engine внутри Vehicle): `Engine` создаётся в конструкторе `Vehicle` и уничтожается вместе с ним. Двигатель не существует без транспортного средства. В коде `Engine` хранится как значение (не указатель) — время жизни связано.

**Агрегация** (Driver* в Vehicle): `Driver` существует независимо. `Vehicle` хранит указатель (`Driver*`), но не владеет объектом. При уничтожении `Vehicle` водитель продолжает существовать. Один водитель может быть назначен нескольким ТС.

## Класс vs структура

В C++ `class` и `struct` отличаются только модификатором доступа по умолчанию: у `class` — `private`, у `struct` — `public`. Оба поддерживают наследование, виртуальные методы, конструкторы. По конвенции `struct` используется для простых структур данных (POD), `class` — для объектов с инвариантами и поведением.

## Передача параметров

- **По значению** (`int x`) — создаётся копия, изменения не видны вызывающему.
- **По ссылке** (`int& x`) — передаётся оригинал, изменения видны.
- **По const-ссылке** (`const string& s`) — без копирования, без возможности изменения. Оптимально для больших объектов.
- **По указателю** (`int* x`) — передаётся адрес, можно передать `nullptr`.
- **Move-семантика** (`string&& s`) — передача владения без копирования. Используется с `std::move()`.

## Исключения

Реализована иерархия исключений: `VehicleException` (базовый, наследует `std::runtime_error`), `SpeedLimitException` (превышение скорости), `FleetIndexException` (выход за границы), `EngineException` (ошибки двигателя). Каждое исключение хранит контекстные данные (скорость, лимит, индекс). Обработка через `try/catch` с ловлей конкретных типов и базового `std::exception`.

## Коллекция и UI

Класс `Fleet` содержит `std::vector<std::unique_ptr<Vehicle>>` и предоставляет `operator[]` для доступа по индексу. UI реализован на Qt 6: вкладки «Флот» (карточки-квадраты с названиями объектов), «Полиморфизм» (вызов виртуальных методов), «Исключения» (демонстрация обработки ошибок), «О классах» (описание иерархии и принципов).
